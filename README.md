# 🐱 Котопокалипсис: Выживание (Cat Survivor - Battle Arena)

Захватывающий Roguelite / Vampire Survivors-подобный экшен на **Phaser 3**, созданный специально для площадки **Яндекс.Игры** с полной поддержкой мобильных устройств и ПК.

---

## 🎮 Особенности игры

1. **Геймплей в стиле Vampire Survivors**:
   - Автоматическая атака и прицеливание по врагам.
   - Огромные орды противников: мыши, собаки, летающие голуби, токсичные плевуны, легендарные безумные огурцы и два мощных босса!
   - Богатый арсенал оружия и пассивных способностей:
     - 🐟 **Рыбный бумеранг** (пробивает врагов и возвращается в лапки)
     - 🧶 **Клубок ниток** (рикошетит между зомби)
     - 🎵 **Мурчащая аура** (периодический звуковой урон по площади)
     - 🔴 **Лазерная указка** (смертоносный точечный луч)
     - 🩴 **Тапок возмездия** (тяжелый knockback и крит)
     - ⚔️ **Вихревые когти** (круговой размашистый удар когтями)
     - 🧪 **Колба с валерьянкой** (параболический бросок, разбивание колбы с осколками, токсичная лужа и замедление врагов)
     - 💣 **Мяу-мина** (наземная кошачья мина с анимацией боевой готовности и эпичным взрывом с отпечатком кошачьей лапки)
     - ⚡ **Статическая шерсть** (цепная молния по ближайшим целям с оглушением)
     - 🌿 **Кошачья мята** (+скорость атаки и бега)
     - 🥛 **Свежее молочко** (пассивная регенерация HP)
     - 🐾 **Острые коготки** (+урон всех атак)
     - 🧲 **Магнитная лапка** (+радиус притягивания опыта и монет)
     - 🛡️ **Густая шерстка** (снижение входящего урона)

2. **Система супер-эволюций оружия (Evolutions)**:
   - При прокачке базового оружия до 5 уровня и наличии парной пассивки открывается легендарная эволюция:
     - 🦈 **Золотая Акула-Меч** (*Рыба + Когти*) — огромная акула непрерывно крушит всё вокруг кота.
     - 🕸️ **Плазменная Паутина** (*Клубок + Мята*) — связывает орды зомби смертоносной электрической сеткой.
     - ☀️ **Священный Мур-Купол** (*Аура + Шерстка*) — постоянный световой барьер с колоссальным уроном и отталкиванием.
     - 🛰️ **Орбитальный Луч «МЯУ-1»** (*Лазер + Магнит*) — 3 вращающихся лазерных спутника испепеляют зомби.
     - 🩴 **Град Бабушкиных Тапок** (*Тапок + Молочко*) — непрерывный ковровый обстрел тяжелыми тапками по экрану.
     - ⚔️ **Когти Росомахи** (*Вихревые когти + Когти*) — 360-градусный вихрь адамантиевых лезвий.
     - 🌪️ **Буря валерьянки** (*Валерьянка + Мята*) — гигантский токсичный водоворот с длительным замедлением и уроном.

3. **Полноценная покадровая анимация**:
   - Персонажи-котики: бег (Run, 4 кадра), покой (Idle, 2 кадра с дыханием и морганием), реакция на урон (Hurt).
   - Враги: походка мышей, бег собак, прыжки огурцов, полет голубей, шаги плевунов, анимации боссов.
   - Оружие: вращающиеся склянки зелья, осколки стекла, пробуждение и анимация угрозы у мин, отпечаток кошачьей лапы во взрыве.

4. **Персонажи и баланс**:
   - 💀 **Барсик (Хардкор)**: 95 HP, враги бегут быстрее и бьют больнее — истинный вызов для скилла!
   - ⚡ **Мурзик (Скорость)**: быстрый ниндзя-кот (+20% скорости).
   - 🛡️ **Пухляш (Танк)**: мощный кот-танк (+50% здоровья).

5. **Боссы и Таинственные Сундуки Удачи**:
   - ⚠️ **Робот-Пылесос Босс** (2:00) и **Генерал Мясорубка / Бульдозер** (4:30) с полосой здоровья босса на экране и звуковой сиреной.
   - Боссы роняют **Золотой Таинственный Сундук** (Mystery Chest), гарантирующий мгновенную супер-эволюцию или прокачку + кучу монет!

6. **Механика Рывка (Dash)**:
   - Клавиша **Пробел** на ПК или кнопка **⚡ РЫВОК** на смартфонах.
   - Дает неуязвимость на время рывка, ускорение 3.2x и облако пыли из-под лапок.

7. **Полная интеграция с Яндекс.Играми (SDK v2)**:
   - Автоматический старт `LoadingAPI.ready()`.
   - Межстраничная полноэкранная реклама (`showFullscreenAdv`) с умным кулдауном.
   - Реклама за вознаграждение (`showRewardedVideo`): воскрешение, удвоение монет, реролл.
   - Облачные сохранения (`ysdk.getPlayer().setData / getData`) с безопасным fallback в `localStorage`.
   - Таблица лидеров по количеству побежденных зомби.

8. **Управление**:
   - **ПК**: Клавиши `W, A, S, D` или Стрелочки на клавиатуре, Пробел для рывка.
   - **Смартфоны**: Динамический виртуальный сенсорный джойстик и сенсорная кнопка рывка.

9. **Полная автономность (Offline-first)**:
   - Все звуковые эффекты и мелодии синтезируются через **Web Audio API** без внешних зависимостей.

## 🚀 Как запустить локально для теста

Запустите локальный HTTP-сервер:
```bash
python -m http.server 8080
```
Затем откройте в браузере: `http://localhost:8080`

---

## 📦 Сборка архива для Яндекс Игр

Для создания архива `game.zip` для консоли разработчика Яндекс Игр:
```bash
python build_zip.py
```
Файл `game.zip` создается в корне проекта и готов к моментальной загрузке в консоль.
Иконка игры (512x512) находится в `assets/icon_512.png`.
